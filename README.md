# ゼルグの旅人

恐怖で保たれた世界を、信頼で変えられるか。六つの結末を辿る、日本語のノベルゲームです。

主人公は旅を続けながら、出会う人々と関わります。選ぶ言葉と行動によって、物語は六つの結末のいずれかへ向かいます。

- ジャンル：ビジュアルノベル（選択肢あり）
- 形式：静的な Web ページ（ビルド工程なし）。ブラウザだけで遊べます
- 対応：スマートフォンの**横向き専用**です。縦向きでは案内が表示され、物語は進みません

## プレイ方法

### 始める・続ける

- **物語をはじめる**：確認なしで最初から始まります。自動セーブの内容は新しい進行に置き換わります（後述「保存の仕様」）。
- **つづきから**：自動セーブの位置から再開します。読み込めない場合は、理由が表示されます。
- **記憶の書庫**：到達した結末の数と、これまでの結末の内容を確認できます。未到達の結末は伏せられています。
- **CG 鑑賞**：解放済みの CG を一覧し、拡大して見られます（後述）。
- **設定・セーブ**：文字の速さ、音量、手動セーブ（3 枠）、読込、セーブコードの書き出し・復元があります。

### 文章を読む

- 画面の文章欄をタップすると、文章を進みます。キーボードでは Space または Enter で進みます。
- 文章が表示中にタップすると、表示を完了します。もう一度タップすると次へ進みます。
- **AUTO**：文章を自動で進めます。選択肢がある行に達すると、選択肢が表示されて止まります。
- **既読 SKIP**：読んだことのある文章を、表示を省いて進めます。未読の文章で止まります。選択肢が出る行でも止まります。
- **履歴**：これまでの文章を読み返せます。
- **断片**：旅の中で見つかった記憶の断片と、登場人物との関係の度合いを確認できます。
- **SAVE / MENU**：手動セーブ、タイトルへ戻る操作があります。

### 選択肢

- 選択肢は、表示された後に行った、ポインター（タップ・クリック）またはキー押下で決まります。
- AUTO や既読 SKIP で選択肢が出た場合、その操作を続けても選択は決まりません。

### 音声

- 画面上部の**音アイコン**で、すべての音声を入／切できます。初期状態は「切」です。
- **設定・セーブ** の「音声」では、BGM、環境音、効果音の音量を別々に調整できます。スライダーを離すと、その種類の参考音が鳴ります。
- 「文字の速さ」は、文章の表示速度です。

### CG 鑑賞

- 「物語の場面」と「旅のひとこま」の二つのタブがあります。
- 解放されていない CG は、鍵の表示になり、題名や画像は表示されません。
- 拡大表示では、画像をタップすると題名と操作欄が隠れます。「一覧へ戻る」で一覧に戻ります。

### 全画面・ホーム画面での利用

- タイトル画面の「全画面で開く」は、全画面表示に対応した環境でだけ表示されます。
- ホーム画面に追加すると、ブラウザの操作欄なしで起動できます。タイトル画面の「ブラウザの操作欄なしで遊ぶ」から、iPhone での追加手順を確認できます。
- ホーム画面からの起動は、Safari の保存領域とは別になります（後述「保存の仕様」）。

## 保存の仕様

すべての保存は、プレイしているブラウザの中（localStorage）に行われます。サーバーには送信されません。

| データ | 保存先 | 内容 |
|---|---|---|
| 進行、既読、結末、手動セーブ、設定 | `zelg-v1` | 手動セーブ 3 枠、自動セーブ、既読、到達した結末、文字の速さ、音声設定 |
| CG 解放 | `zelg-gallery-v1` | 解放済みの CG の名前だけ |
| 移行前のバックアップ | `zelg-v1-backup-full-v20` | 版を移行したときに、移行前の `zelg-v1` の内容を一度だけ保存します |

### 項目ごとの扱い

- **手動セーブ**：3 枠。上書き時は確認があります。
- **自動セーブ**：場面を進むたびに更新されます。「つづきから」で使います。
- **既読**：読んだ文章の記録。既読 SKIP に使います。保存の版が古い場合は、版ごとの移行処理で現行の行へ移します。
- **結末**：到達した結末の記録。「記憶の書庫」に表示されます。
- **CG 解放**：CG の解放記録。一度解放された CG は外れません。取り込んだ進行で読んだ場面に対応する CG が、新たに解放されることがあります。
- **設定**：文字の速さ、音声 ON/OFF、音量（BGM・環境音・効果音）。

### 「物語をはじめる」で変わるもの・残るもの

- **変わる**：自動セーブ（つづきから）の内容。新しい進行が保存されます。
- **残る**：手動セーブ 3 枠、既読、結末、CG 解放、設定。

### エクスポートとインポート

- **設定・セーブ** から、書き出し時点の進行、既読、結末を、テキストの「セーブコード」として書き出せます。コードは `ZELG1.` で始まります。
- インポートでは、コードの形式と内容を確認してから読み込みます。コードの内容が正しくない場合、現在の保存データは変わりません。
- インポートは、取り込んだ進行で現在の進行を置き換えます。既読と結末は、既存の記録に加えて統合されます。手動セーブ 3 枠は変わりません。
- セーブコードは、アプリから外部へ送信されません。他の人に渡す場合は、内容を理解したうえで扱ってください。

### 注意

- ブラウザのデータ（サイトデータ、閲覧履歴の消去）を消すと、保存は失われます。事前にセーブコードを書き出してください。
- 保存は、同じブラウザ・同じ端末の中だけで使われます。別のブラウザや別の端末には、セーブコードを使って移してください。ホーム画面から起動したアプリと、Safari の保存は別になります。
- 保存はクラウドには同期されません。

## 開発を始める

### 必要な環境

- Git
- 静的ファイルを配信できる HTTP サーバー（例：Python 3 の標準機能）
- 現代的なブラウザ（開発中は Chromium で確認しています）
- 対応表の再生成には、Node.js（任意）

このリポジトリには `package.json` がありません。`npm install` やビルドの手順はありません。

### ローカルでの起動

リポジトリの直下で、HTTP サーバーを起動します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

`index.html` を `file://` で直接開くと、音声や一部の読込が動かない可能性があります。確認していないため、HTTP サーバーで開いてください。

### 主要なファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みと、読み込む順番。Content-Security-Policy（後述）もここに書かれています |
| `story.js` | 本文の正本。場面、行、話者、分岐、選択肢、行 ID（`PAGE_IDS`） |
| `app.js` | 進行、表示、保存、既読、セーブコード、版の移行 |
| `style.css` | 画面の見た目。横向き以外の案内を含む |
| `backgrounds.js` | 背景の割り当て（場面内の行番号の範囲）と背景の版 |
| `stage.js` | 立ち絵の割り当て（場面・話者ごとの行番号） |
| `portraits.js`、`portraits.css` | 立ち絵の定義と表示 |
| `cg.js` | CG の定義と、場面内での表示範囲（行 ID で指定） |
| `gallery.js` | CG 鑑賞と、CG 解放の記録 |
| `audio.js` | 音声の再生。BGM、環境音、効果音、音量の制御 |
| `seen-map.js` | 旧版の既読を現行の行へ移す対応表（生成物。後述） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前、アイコン、横向き設定 |
| `tools/make-seen-map.js` | `seen-map.js` を git 履歴から生成するスクリプト |

### 開発用プレビュー

本編とは別に、素材を確認するための Web ページがあります。これらは本編の保存を読み書きしません。

| ページ | 役割 | 指定の例 |
|---|---|---|
| `cg-preview.html` | CG の表示を確認する | `cg-preview.html?cg=confession` |
| `character-preview.html` | 立ち絵の表情と背景を確認する | `character-preview.html?character=riene&expression=happy` |
| `effects-preview.html` | 文字や演出の効果を比べる | `effects-preview.html?level=weak&bg=dark` |

プレビューは、本編の `index.html` と同じ公開ファイルです。公開のための追加設定はありません。

### 素材の配置

素材はすべて `assets/` の下にあり、パスは各 JS の定義から読み込まれます。

| フォルダ | 内容 | 形式 |
|---|---|---|
| `assets/backgrounds/` | 背景 | `.webp`。`town_day.png` と `town_day_repaint.png` は元の PNG で、現在の表示では使っていません |
| `assets/cg/` | CG（イベント画像） | `.webp`（23 枚） |

素材を追加するときは、対応する JS の定義にも追加してください。定義がない素材は、本編では読み込まれません。

## 変更時の設計上の注意

本文の変更手順は、[docs/CONTENT-CHANGES.md](docs/CONTENT-CHANGES.md) にまとめています。ここでは、変更の前に知っておくべき関係を示します。

### 場面と行 ID

- 行は、場面の中の順番（行番号）と、行 ID の二つで管理されます。
- 行 ID は `story.js` の `PAGE_IDS` にあり、本文と同じ数だけ並んでいます。
- CG、BGM、効果音、環境音は行 ID で指定されているため、行番号が変わっても同じ行を指します。
- 背景と立ち絵は、行番号の範囲で指定されています。行を追加・削除したら、これらを手で更新してください。

### 本文の変更と保存

- 保存には、場面の ID と行番号が記録されます。行番号が変わると、保存された位置の意味も変わります。
- 既読は、場面名と行番号で記録されます。文章の意味が変わった行は、既読として扱うかどうかを慎重に決めてください。
- 旧版の既読は、`seen-map.js` の対応表で現行の行へ移されます。対応表は、行 ID が同じで、話者と本文（空白を除く）が一致する行だけを引き継ぎます。
- 対応表は、`tools/make-seen-map.js` で git 履歴から生成します。生成物を手で編集しないでください。

### キャッシュ

- ブラウザは、同じ URL のファイルを保存して再利用します。変更したファイルを読み込み直させるため、`index.html` の script と link の `?v=` を上げます。
- 背景の画像は、`backgrounds.js` の `BG_VERSION` で一括して更新します。
- CG の画像は、`cg.js` の各定義の `?v=` で更新します。

### seen-map の生成

```sh
node tools/make-seen-map.js --stats          # 版ごとの対応の件数
node tools/make-seen-map.js > seen-map.js    # 対応表を書き出す
```

- 生成には git の履歴が必要です。
- 対応表が対象とする版（`REVS`）は `tools/make-seen-map.js` の中にあります。新しい版を作ったときは、この一覧を更新してから再生成してください。

### 検証

- リポジトリに自動テストはありません。
- 変更の確認は、[docs/CONTENT-CHANGES.md](docs/CONTENT-CHANGES.md) の「確認の基本手順」に従ってください。
- 保存の移行を変えた場合は、旧版の保存を読み込んで、既読や位置が意図どおりか確認してください。

## 公開とセキュリティ

### GitHub Pages

- `main` ブランチへの push で、GitHub Pages のビルドが実行されます（配信履歴で確認できます）。
- リポジトリ直下の `.nojekyll` は、Jekyll による処理を止めるために置かれています。
- 公開される内容は、リポジトリの追跡ファイルと一致します。`.gitignore` で除外しているファイル（作業用の `.claude/` など）は公開されません。`tools/` と `docs/` も公開されます。秘密情報は含めていません。
- 公開範囲（公開するブランチ、カスタムドメイン、HTTPS の強制）は、リポジトリの Settings で設定されます。コードからは確認も変更もできません。

### Content-Security-Policy（CSP）

本編の `index.html` には、`<meta http-equiv="Content-Security-Policy">` が書かれています。内容は次のとおりです。

- `default-src 'self'`、`script-src 'self'`、`connect-src 'self'`、`img-src 'self'`、`manifest-src 'self'`：読み込みは同じオリジンのファイルに限ります。
- `style-src 'self' 'unsafe-inline'`：CSS の読み込みと、`style` 属性を許可します。断片の画面で、関係の度合いを示す幅を `style` 属性で設定しているため、この許可が必要です。
- `media-src 'none'`、`font-src 'none'`、`object-src 'none'`、`frame-src 'none'`、`worker-src 'none'`、`base-uri 'none'`、`form-action 'none'`：使っていない種類の読み込みを止めます。
- スクリプトには `unsafe-inline` と `unsafe-eval` を許可していません。

**対象範囲**：この CSP は `index.html` だけに付いています。開発用プレビューの各ページには付いていません。

**限界**：meta タグでは、`frame-ancestors`（埋め込みの制限）、`report-uri`（違反の報告先）、`sandbox` を指定できません。これらが必要な場合は、ホスティングの応答ヘッダーで設定する必要があり、GitHub Pages ではリポジトリから設定できません。

### 外部通信と保存データ

- 本編は、同じオリジンの素材ファイルだけを読み込みます。外部のサーバーへの通信はありません。
- 保存データは、ブラウザの localStorage に保存されます。
- 保存コードは、利用者が自分で書き出し、自分で読み込みます。

### GitHub 側で管理するもの（コードでは変えられない）

- リポジトリの公開範囲、Pages の設定、ブランチの保護、アクセス権、2 段階認証。
- 応答ヘッダー（CSP 以外の HTTP ヘッダー、キャッシュの制御）。
