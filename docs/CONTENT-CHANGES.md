# 本文を変更する手順

この文書は、`story.js` の本文・分岐・選択肢や、場面に結び付く背景、立ち絵、CG、音声を変えるときの手順です。概要は [README.md の「本文を変更するとき」](../README.md#本文を変更するとき) にあります。ローカルでの起動方法は [README.md の「開発を始める」](../README.md#開発を始める) を参照してください。

## 1. 変更の種類を判定する

| 変更の種類 | 既読の扱い | 版 |
|---|---|---|
| 空白・改行だけの変更 | 維持 | 上げない |
| 話者または本文の文字が変わる（句読点や言葉の修正を含む） | その行の既読は解除される | 上げる |
| 行を追加・削除・並べ替える | 保存と既読の位置を移す必要がある | 上げる |

既読の移行は、行 ID が同じで、話者と本文（空白を除く）が一致する行だけを引き継ぎます。文字が一つでも変わった行は、既読として引き継がれません。文字の変更を既読へ反映するには、版を上げる必要があります。

## 2. 場面と行 ID

- 本文は `story.js` の `scene(id, ch, title, lines, next, choices)` で定義します。`lines` は `[話者, 本文]` の配列です。
- 各場面には、行と同じ数の行 ID を並べた `PAGE_IDS[場面]` があります（同じ `story.js` の中にあります）。行 ID は `prologue-001` のような形式で、全体で一意です。

確認に使う検査（ブラウザの開発者コンソールで、読み込んだ状態で実行します）:

```js
const bad = Object.keys(STORY).filter(n => (PAGE_IDS[n] || []).length !== STORY[n].lines.length);
const ids = Object.values(PAGE_IDS).flat();
console.log('行数と ID の不一致:', bad, '重複 ID の数:', ids.length - new Set(ids).size);
```

## 3. 参照方法の違い

| 対象 | 指定の仕方 | 行を追加・削除したときの扱い |
|---|---|---|
| 背景（`backgrounds.js` の `BG_SEGMENTS`） | 場面内の行番号の範囲 | 行番号がずれるため、範囲を手で更新する |
| 立ち絵（`stage.js` の `STAGE`） | 場面・話者ごとの行番号の配列 | 配列の位置を更新する |
| CG（`cg.js` の `CG_SEGMENTS`、`TRIP_UNLOCKS`） | 行 ID | 行 ID が同じなら変更不要 |
| BGM（`audio.js` の `BGM_CUES`） | 行 ID | 行 ID が同じなら変更不要 |
| 効果音（`audio.js` の `SOUNDS`）、環境音（`AMBIENCE`） | 行 ID | 行 ID が同じなら変更不要 |

背景と立ち絵は行番号で指定されているため、行を追加・削除する変更では、必ずこれらを同時に更新してください。

## 4. 版を上げる手順

現在の本文の版は、`app.js` の `OPENING_REV` です。

1. **変更前の状態を登録する**：変更の前の最後のコミットを、`tools/make-seen-map.js` の `REVS` に、直前の版の名前で登録します。対応表はこの登録をもとに、旧版の行を現行の行へ対応させます。
2. **版の名前を変える**：`app.js` の `OPENING_REV` を、新しい版の名前にします。
3. **直前の版の保存を読めるようにする**：直前の版の保存を新しい版へ写す処理を、`app.js` の `migrateState` に追加します。行の位置が変わらない場合も、直前の版を新しい版へ写す処理は必要です。これがないと、直前の版の保存は読み込めません。
4. **対応表を再生成する**：

   ```sh
   node tools/make-seen-map.js --stats          # 版ごとの対応の件数を確認
   node tools/make-seen-map.js > seen-map.js    # 対応表を書き出す
   ```

   生成には git の履歴が必要です。対応表の対象は `REVS` に登録された版です。`seen-map.js` を手で編集しないでください。
5. **キャッシュを更新する**：`index.html` の `seen-map.js?v=`、`app.js?v=` を上げます。背景の画像は `backgrounds.js` の `BG_VERSION`、CG の画像は `cg.js` の各定義の `?v=` で更新します。

行を追加・削除しない変更でも、空白以外の文字が変わるなら、手順 1 から 5 を行います。

## 5. 確認の基本手順

リポジトリに自動テストはありません。次を手で確認してください。

1. HTTP サーバーで開きます（README の「開発を始める」を参照）。
2. 変更した場面を開発者コンソールから開きます。`start` はグローバル関数として、コンソールから呼べます。

   ```js
   start({ ...fresh(), node: '場面名', line: 行番号 });
   ```

3. 変更した行、その前後、背景、立ち絵、CG、音声が正しいことを確認します。
4. 版を上げた場合は、直前の版の保存（手動セーブと自動セーブ）を読み込み、場面と行が意図どおりか確認します。
5. 既読を持つ保存で既読 SKIP を使い、未読の変更文で止まることを確認します。
6. 現在の版の保存が問題なく読み込めることを確認します。
