# 本文を変更するときの手順

この文書は、`story.js` の本文・分岐・選択肢や、場面に結び付く演出（背景、立ち絵、CG、音声）を変えるときの手順です。変更の前に、ここに書かれた対応関係を確認してください。

## 1. 場面と行 ID

- 本文は `story.js` の `scene(id, ch, title, lines, next, choices)` で定義します。`lines` は `[話者, 本文]` の配列です。
- 各場面には、行と同じ数の**行 ID** を並べた `PAGE_IDS[場面]` があります（同じ `story.js` の中にあります）。行 ID は `prologue-001` のような形式で、全体で一意です。
- 行 ID と行番号の対応は、次の項目を確認してから変えてください。

確認に使える検査（ブラウザの開発者コンソールで、リポジトリの `story.js` を読み込んだ状態で実行します）:

```js
const bad = Object.keys(STORY).filter(n => (PAGE_IDS[n] || []).length !== STORY[n].lines.length);
const ids = Object.values(PAGE_IDS).flat();
console.log('行数と ID の不一致:', bad, '重複 ID:', ids.length - new Set(ids).size);
```

## 2. 参照方法の違い（変更時に最も注意する点）

| 対象 | 指定の仕方 | 行を追加・削除したときの扱い |
|---|---|---|
| 背景（`backgrounds.js` の `BG_SEGMENTS`） | 場面内の**行番号の範囲** | 行番号がずれるため、範囲を手で更新する |
| 立ち絵（`stage.js` の `STAGE`） | 場面・話者ごとの**行番号の配列** | 配列の長さと位置を更新する |
| CG（`cg.js` の `CG_SEGMENTS`、`TRIP_UNLOCKS`） | **行 ID** | ID が同じなら変更不要 |
| BGM（`audio.js` の `BGM_CUES`） | **行 ID** | ID が同じなら変更不要 |
| 効果音（`audio.js` の `SOUNDS`）、環境音（`AMBIENCE`） | **行 ID** | ID が同じなら変更不要 |

背景と立ち絵は行番号で指定されているため、行の追加や削除を伴う変更では、これらを必ず同時に直してください。文章だけを直す変更（行数と ID が変わらない変更）は、この表の対応を変えません。

## 3. 保存と既読への影響

- 保存は、場面の ID と行番号、現行の版（`contentRevision`）で記録されます。版は `app.js` の `OPENING_REV` が現行の値です。
- 既読（`seen`）は `場面:行番号` で記録されます。行番号が変わると、既読の意味も変わります。
- 旧版の既読は、`seen-map.js` の対応表で現行の行へ移します。表は `tools/make-seen-map.js` が git 履歴から生成します。

**本文の意味を変える変更**（既読の扱いを変えたい変更）は、版を上げることを検討してください。版を上げる作業は、保存位置の移行（`app.js` の `migrateState` と `toCurrent`）と、既読の対応表の両方に、新しい版を追加する作業になります。既存の版の処理を読んでから着手してください。誤字の修正など、意味を変えない変更は、版を上げずに行えます。

## 4. 変更の手順

1. `story.js` の本文・分岐・選択肢を変更します。
2. 行数を変えた場合は、`PAGE_IDS` を同じ数にします（1 の検査を実行します）。
3. 行数を変えた場合は、`backgrounds.js` の `BG_SEGMENTS` と `stage.js` の `STAGE` の行番号を更新します（2 の表）。
4. CG、BGM、効果音、環境音の指定は、行 ID を基準にしているため、ID を保てば変更は不要です。新しい行に音や CG を付けるときは、ID で指定してください。
5. 版を上げる場合は、3 の作業を行い、`tools/make-seen-map.js` の対象版（`REVS`）を更新して、対応表を再生成します。

   ```sh
   node tools/make-seen-map.js --stats          # 版ごとの対応の件数を確認
   node tools/make-seen-map.js > seen-map.js    # 対応表を書き出す
   ```

   生成には git 履歴が必要で、`REVS` に書かれた各版のコミットを読みます。
6. 変更したファイルを読み込む `index.html` の `?v=` を上げます（キャッシュ更新。`index.html` の script と link の版の番号を確認してください）。背景の画像 URL は `backgrounds.js` の `BG_VERSION` で一括して更新します。CG 画像の版は `cg.js` の `src` の `?v=` にあります。

## 5. 確認の基本手順

リポジトリに自動テストはありません。次を手で確認してください。

1. ローカルの HTTP サーバーで開きます（後述の「開発を始める」を参照）。
2. 変更した場面を開発者コンソールから開きます。`start` はグローバル関数として、コンソールから呼べます。

   ```js
   start({ ...fresh(), node: '場面名', line: 行番号 });
   ```

3. 変更した行、その前後、背景、立ち絵、CG、音声が正しいことを確認します。
4. 既読の扱いを変えた場合は、既読を持つ保存を読み込み、既読の送り（既読 SKIP）が未読の行で止まることを確認します。
5. 既存の保存（手動枠、自動セーブ）を読み込めることを確認します。
