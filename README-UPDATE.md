既存のstory.jsとassetsフォルダはそのまま使います。このZIPに画像は含みません。README-UPDATE.mdのアップロードは任意です。

## 必要な画像

assets/characters/riene/ に normal.png、happy.png、worried.png、sad.png、angry.png、crying.png が必要です。公開先の全6枚について、HTTP 200・RGBA透過・686×1024pxを確認しました。

## 表示

- リーネとの出会い以降、場面とページに合わせて表情を切り替えます。
- リーネ以外の人物の台詞では少し暗く表示します。
- プロローグ、孤独なルート、リーネのその後を描かない犠牲・崩壊の後日談では表示しません。
- 横向きスマートフォンでは顔を読み取りやすい大きさにし、下半身は画面とテキストウィンドウの下に収まる構図です。
- シナリオ本文、エンディング条件、保存形式は変更しません。既存セーブからも表示されます。

## 調整箇所

riene.js の RIENE_PORTRAITS で、シーンごとに各ページの表情を指定できます。ページ番号は0始まりです。nullは非表示です。

CSSの #rienePortrait で表示位置・大きさを調整できます。画像自体の切り抜き位置は変更しないでください。

## 確認状況

JavaScript構文、全シーンの表情指定、画像ファイルの存在、本文・分岐判定とセーブコードの互換性を簡易検証しました。更新後のブラウザ描画・実機表示は未検証です。

公開後、プロローグから進めてリーネの登場を確認してください。以前の画面が残る場合は再読み込みしてください。
